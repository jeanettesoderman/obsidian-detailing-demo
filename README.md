# Obsidian Detailing demo v1

Demo nummer 3 i webbplatskatalogen.

## Stil
Mörk premiumdesign med:
- svart / grafit
- guld
- djup blå
- blank showroom-känsla

## Anpassning
Det mesta ligger i `config.js`:
- företagsnamn
- telefon och e-post
- område
- hero-text
- om-text
- tjänster
- paket
- priser
- före/efter-sektion
- bilder
- formulärläge

## Kundbilder
Lägg kundens bilder i `images/` och byt sökvägarna i `config.js`.

## Publicering
Samma flöde som övriga demos:
VS Code → GitHub → Netlify.
