# Obsidian Detailing demo v1

Demo nummer 3 i webbplatskatalogen.

## Stil
Mörk premiumdesign med:
- svart / grafit
- guld
- djup blå
- blank showroom-känsla

## Anpassning
Det mesta ligger i `config.js`:
- företagsnamn
- telefon och e-post
- område
- hero-text
- om-text
- tjänster
- paket
- priser
- före/efter-sektion
- bilder
- formulärläge

## Kundbilder
Lägg kundens bilder i `images/` och byt sökvägarna i `config.js`.

## Publicering
Samma flöde som övriga demos:
VS Code → GitHub → Netlify.


## Multilingual complete local-test version
Languages:
Svenska, English, Dansk, Deutsch, Español, Français, Italiano, Português.

Before pushing to GitHub/Netlify:
1. Open locally with VS Code Go Live.
2. Test `?lang=en`, `?lang=de`, and `?lang=it`.
3. Scroll from header to footer.
4. Check navigation, service cards, before/after cards, packages, reviews, booking form, placeholders, select options, contact bar and footer.
5. Only push when the local version looks correct.

Prices intentionally remain based on the Swedish demo's SEK amounts. The wording around each price is translated.
